# Deployment

The deployment runbook lives in
[`docs/development/deployment.md`](docs/development/deployment.md), published
at <https://heig-tin-info.github.io/heig-quiz/development/deployment/>.

Comments in the scripts and the compose files cite "deploy.md §n":
the runbook keeps the same numbering.

| § | Section |
| --- | --- |
| 1 | DNS |
| 2 | The application VM (`/srv/quiz`) |
| 3 | The runner VM (`/opt/quiz-runner`) |
| 4 | Continuous deployment (CI, forced-command keys) |
| 5 | Deploying, and rolling back |
| 6 | Backups |
| 7 | Monitoring |
| 8 | Staging (`quiz.dev.chevallier.io`) |
