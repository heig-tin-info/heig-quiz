## Consequences for the decisions

- **D08**: `sub` is excluded from matching. Cascade: `swiss_edu_id` →
  verified address → new user + login adoption (required, M1-06 carries it
  with its ADR).
- **D09**: the online workspace has never served a real class ⇒ M6 leaves
  the critical path (runs after the cutover); the 3 test assignments are
  imported as `free` or dropped with their test classrooms.
- **D04 (b)**: no pending staff seat ⇒ nothing to build; the one assistant
  becomes a course staff seat.
- **Groups**: one group-mode assignment, no group repository yet — M3-15/16
  stay in scope (the feature is in use) but carry no data risk.
- **Journal**: tiny (4 pages, no asset): D14 is not a sizing question.
