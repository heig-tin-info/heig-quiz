Question 6 · code · répondu il y a 8 s

Énoncé

Écrivez int somme(const int *t, size_t n) qui renvoie la somme des n premiers éléments de t. Un tableau vide renvoie 0.

Réponse de l'étudiant

int somme(const int *t, size_t n) {
    int s = 0;
    for (size_t i = 0; i <= n; i++) {
        s += t[i];
    }
    return s;
}

Cas 2 — tableau viden = 0 · attendu 0 · obtenu 0
