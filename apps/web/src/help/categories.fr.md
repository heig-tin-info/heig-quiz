# Les catégories d'une banque

Les catégories rangent les questions d'une banque dans une arborescence de
dossiers. Une question est dans une catégorie, ou dans aucune (**Sans
catégorie**, tout en bas).

## Nombres

Le nombre de chaque ligne compte les questions rangées **directement** dans
cette catégorie : ce que montre la liste des questions quand on la choisit.
Un clic sur le nombre ouvre cette liste.

## Modifier l'arborescence

- **Nouvelle catégorie** en crée une au premier niveau ; le menu d'une ligne
  crée une sous-catégorie dedans.
- Un clic sur un nom (ou F2) le renomme sur place. Entrée enregistre,
  Échap annule.
- **Glissez** une catégorie sur une autre pour l'y ranger, ou entre deux
  lignes pour la réordonner.
- **Au clavier**, sur un nom : Alt+↑ et Alt+↓ la déplacent parmi ses
  voisines, Alt+→ la range dans la catégorie du dessus, Alt+← la sort de son
  parent. Le menu de la ligne propose les mêmes déplacements, et
  **Déplacer vers…** choisit n'importe quel nouveau parent.

## Supprimer

Supprimer une catégorie supprime aussi ses sous-catégories. Leurs questions
repassent à la racine de la banque ; aucune question n'est supprimée ainsi.
