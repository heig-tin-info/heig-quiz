# Mon projet

## Les étapes

1. **Lier GitHub**, une seule fois. Vous revenez sur cette page.
2. **Accepter** : votre dépôt privé est créé, en une minute au plus.
3. **Ouvrir l'invitation** : acceptez-la sur GitHub, une seule fois. Perdue ?
   **Renvoyer l'invitation**.
4. **Ouvrir le dépôt**, puis clonez-le, travaillez et poussez.

La page n'affiche qu'un bouton à la fois : l'étape suivante.

## Votre score

Le score sous **Score** vient du dernier commit qui a été évalué. Il est
**indicatif** : il change à chaque push et ce n'est pas votre note. **Pas
encore de score** signifie qu'aucun de vos commits n'a été évalué.

## Fichiers protégés

Certains fichiers (le workflow d'évaluation, les consignes) sont protégés. Si
un push en modifie un, un commit remet la version de l'enseignant. Votre
travail reste ; votre modification de ce fichier ne compte pas.

## Mises à jour de l'enseignant

Une mise à jour arrive sous forme de pull request sur GitHub. Ouvrez-la,
résolvez les conflits et fusionnez-la vous-même.

## L'échéance

À l'échéance, votre dépôt passe en lecture seule et le score est figé sur le
**Commit évalué**. L'horloge est celle du serveur, pas celle de votre
ordinateur.

## La publication

Dès que votre enseignant publie les scores, la page affiche votre score
final, votre note et le commentaire de l'enseignant. Vous recevez une
notification.
