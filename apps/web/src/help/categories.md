# A pool's categories

Categories file the questions of a pool in a tree of folders. A question sits
in one category, or in none (**Without a category**, at the bottom).

## Counts

The number on each row is the questions filed **directly** in that category,
which is what the question list shows when you pick it. Click the number to
open that list.

## Editing the tree

- **New category** creates one at the top level; a row's menu creates a
  subcategory inside it.
- Click a name (or press F2 on it) to rename it in place. Enter saves,
  Escape cancels.
- **Drag** a category onto another to file it inside, or between two rows to
  reorder it.
- **With the keyboard**, on a name: Alt+↑ and Alt+↓ reorder it among its
  siblings, Alt+→ files it into the category above, Alt+← takes it out of its
  parent. The row's menu offers the same moves, and **Move to…** picks any
  new parent.

## Deleting

Deleting a category deletes its subcategories too. Their questions move back
to the root of the pool; no question is ever deleted this way.
