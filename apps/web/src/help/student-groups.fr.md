# Former votre groupe

## Ce que vous pouvez faire

Tant que votre enseignant garde les groupes ouverts, jusqu'à la date indiquée :

- **Créer un groupe** : vous le rejoignez aussitôt. Le nom est facultatif.
- **Rejoindre** un groupe qui n'est pas complet.
- **Quitter** votre groupe, ou le **Renommer**.

## Ce que vous voyez

Les groupes avec le nom et le nombre de leurs membres, et les étudiants qui
n'ont pas encore de groupe. Rien d'autre à leur sujet.

## À la fin

À la date, les groupes se ferment et votre enseignant place ceux qui n'ont
pas de groupe. Dès qu'un groupe de l'ensemble obtient son dépôt, les groupes
ne peuvent plus changer.

## Projets de groupe

Un membre accepte le projet et le dépôt appartient au groupe. Chaque membre
est invité sur GitHub dès qu'il a lié son propre compte.
