# Cours

## Ce qu'est un cours

Un cours est l'unité durable que vous enseignez — « Programmation C » — avec
un nom et un code court. Il survit à une classe : le même cours porte les
classes de 2026, puis celles de 2027.

Une carte par cours. Ses classes y sont listées avec leur période et leur
effectif ; un clic en ouvre une.

## Classes

**Nouvelle classe** demande un nom et, facultativement, une période. Une
classe est un groupe qui suit ce cours pendant une période ; c'est là que
vivent la liste des étudiants, les évaluations et les résultats.

## Équipe

**Ajouter une personne** prend l'adresse d'un compte qui s'est déjà connecté
au moins une fois. Tous les membres de l'équipe ont les mêmes droits sur les
classes du cours — il n'y a pas de propriétaire. Le menu permet aussi de
retirer quelqu'un de l'équipe.

## Banques de ce cours

Les évaluations d'un cours puisent leurs questions dans les banques qui lui
sont liées. **Lier une banque** en ajoute une ; **Délier de ce cours** retire
le lien et rien d'autre — la banque et ses questions restent en place. Une
banque liée à aucun cours reste la vôtre, elle n'est simplement pas proposée
au moment de remplir une évaluation.

## Supprimer

Supprimer un cours emporte ses classes, leurs listes et leurs résultats,
après une confirmation qui nomme le cours. Ses banques ne sont pas touchées.
