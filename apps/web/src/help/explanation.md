# Explanation

Why the answer is the answer, in your own words. It belongs to the question,
not to the statement: a student answering never receives it.

## When a student reads it

- The evaluation's feedback policy has to carry **Show the explanation** — it is off by default.
- Feedback has to be open: never while the attempt runs, then straight after submitting when the policy says "immediate", otherwise once you release the results.
- A question whose explanation is empty simply sends nothing; the review shows no empty box.

## Writing it

The same editor as the statement, and the same markdown underneath: bold,
formulas, fenced code, pasted images. Write the reasoning a student who got
it wrong needs, not the answer key — that one travels on its own.
