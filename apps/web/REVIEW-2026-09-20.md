# apps/web review — 2026-09-20

Read-only review of `~/quiz/apps/web` (React 19 / Vite / TanStack Query), against
`CLAUDE.md`, `.claude/skills/quiz-ui/SKILL.md`, `apps/web/DESIGN.md`, `docs/PLAN-MVP.md` §6,
`docs/spec/08-experience-deux-niveaux.md`, `docs/spec/03-exigences-non-fonctionnelles.md`,
and `mockups/*.html`.

Method: static greps + a throwaway i18n parity script; then playwright/chromium against
`VITE_MOCK=1 vite --port 5199` — **50 scenes × 3 viewports (1440×900 light, 1440×900 dark,
390×844) = 150 runs**, each collecting console/page errors, failed requests, horizontal
overflow, headings, accent-button counts and a full axe-core pass with `color-contrast`
enabled; plus targeted keyboard, focus-trap and layout probes. Nothing in `~/quiz` was
modified; port 3000 and 5173 were not used.

## Verified OK

- **i18n dictionaries**: 1185 keys in `en`, 1185 in `fr`, no missing, no extra, no empty value,
  no `{var}` mismatch. (`qt.cloze.e.textHint`'s `{{answer}}`/`{{réponse}}` is cloze syntax, not
  interpolation.) No French prose in `en`, no English prose in `fr` — the heuristic hits were all
  cognates ("Question", "Points", "Code", "Administration").
- **No raw colour anywhere**: zero `dark:` variants, zero hex, zero Tailwind palette scales in
  `apps/web/src/**` and `packages/qt-*/src/**`. The one `#000` (`ui.tsx:1559`) is a gradient mask,
  which DESIGN.md sanctions.
- **No `shadow-*` in the page flow**; no `window.confirm` / `alert` / `prompt`.
- **No `console.error`, no `TODO`/`FIXME`/`HACK`** in shipped code. Two `console.warn`: one
  `import.meta.env.DEV`-gated (`useEventStream.ts:93`), one mock-only.
- **Zero console errors, zero uncaught page errors, zero failed requests** across all 150 runs.
- **Zero horizontal page overflow** at 1440×900 and 390×844, light and dark, on all 50 scenes.
- **Routes**: every `Route` member in `router.ts` has a screen in `App.tsx` and vice versa;
  `devUi` is correctly `import.meta.env.DEV`-gated.
- **`<html lang>` follows the locale** (`i18n.tsx:2613`).
- **`text-on-fill` works**: Publish in dark mode is `#131211` on `#e85f64`; axe found no
  ink-on-fill failure anywhere, in either theme.
- **Layer contract holds**: focus moves into the panel on open, stays trapped through 25 Tabs,
  returns to the trigger on Escape; a backdrop click does **not** close a form layer;
  `aria-modal="true"` and `aria-labelledby` resolve to a real title.
- **`Ctrl+K`** opens the palette from anywhere inside the Shell, including from inside a text
  field, and the contextual live commands (Pause, +5 minutes, Close) register on the dashboard.
- **Player keys**: `Alt+→` / `Alt+←` navigate between questions; `Ctrl+Enter` marks done.
- **Dashboard keys**: `n` / `r` / `s` toggle names / answers / results; `f` toggles full screen;
  `Space` pauses and resumes (on a real id — see W17); `Escape` closes the inspect panel.
- **Grading keys**: `v` validates and moves on (queue 5 → 4, score 14/20 → 15/20); `→` / `←`
  move; `o` opens the override sheet; Escape closes it. All guarded against firing inside a
  field or behind an open dialog.
- **Five async states** render on pool, live, grading, results and student home
  (`?slow=1` skeletons, `?empty=1`, `?fail=1`, `—` for partial rows, success).
- Every one of the 21 `QueryError` call sites passes a translated `fallback`.
